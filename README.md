# Khadas Tone2 Maker V12 – Mounting Hole Layout

A dimensioned mounting-hole drawing for the Khadas Tone2 Maker V1.2 board.

The official Khadas mechanical documentation does not explicitly provide all mounting-hole center coordinates. This drawing was created using the official Khadas 3D model to make mechanical design and mounting bracket development easier.

The file `tone2-maker-kit-pcba-v12.pdf` is an official Khadas document included for reference purposes only.

**Contents**
- Mounting hole positions and diameters
- Board dimensions
- Top view with connector references
- PDF and SVG drawings
- Editable FreeCAD source

**Notes**

All dimensions are in millimeters. This is an independently prepared reference drawing, not an official Khadas manufacturing document.

Verify dimensions and PCB revision before manufacturing mating components.
